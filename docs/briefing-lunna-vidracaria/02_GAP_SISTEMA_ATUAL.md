# Gap do sistema atual

## Aderente ao briefing

O sistema atual já está aderente ao fluxo principal informado pelo cliente:

Cliente → Orçamento → Aprovação → Pedido → Agenda → Instalação → Pagamento → Finalização

Também já possui permissões por perfil, proteção no controller, CSRF, página pública, login e dashboard com dados reais.

## Lacunas de curto prazo

- Atalhos de comunicação com cliente por WhatsApp.
- Melhor organização dos documentos de briefing e implantação.
- Remover qualquer indicação pública de que existe um sistema interno.
- Relatórios operacionais mais diretos para vendas, entregas e pagamentos.

## Lacunas de médio prazo

- Contas a pagar.
- Estoque e movimentações de entrada/saída.
- Upload de documentos por cliente, orçamento ou pedido.
- Exportação de dados para Excel/CSV.
- Notificações internas.
- Área do cliente para acompanhamento de pedidos.

## Lacunas de longo prazo

- Integração Google Calendar.
- Integração real com WhatsApp API.
- Assinatura digital.
- Integração com ERP/sistema de pagamento.
- Marketing digital automatizado.

## Riscos

- Escopo grande demais para uma primeira versão.
- Estoque e contas a pagar exigem alteração de banco e regras próprias.
- Área do cliente exige autenticação separada e cuidado com exposição de dados.
- Integrações externas exigem credenciais, custos e políticas de uso.
